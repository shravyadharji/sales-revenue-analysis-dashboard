# Sales & Revenue Analysis Dashboard

## Project Overview

This project presents a Sales & Revenue Analysis Dashboard developed using Power BI. The dashboard helps analyze sales performance, profitability, product performance, and regional sales trends through interactive visualizations.

## Objectives

* Analyze overall sales and revenue performance.
* Identify top-performing products and categories.
* Compare sales across different regions.
* Track sales trends over time.
* Provide actionable business insights.

## Key Performance Indicators (KPIs)

* Total Sales
* Total Profit
* Total Orders
* Total Quantity Sold

## Dashboard Features

* Revenue Trend Analysis
* Sales by Category
* Sales by Region
* Top Performing Products
* Interactive Slicers and Filters

## Tools Used

* Power BI Desktop
* CSV Dataset
* GitHub

## Key Insights

* Revenue trends can be analyzed over different time periods.
* Top-performing products contribute significantly to total sales.
* Sales performance varies across regions and categories.
* Interactive filters enable detailed analysis of business performance.
